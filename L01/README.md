## ผลการทดสอบ

1. วางผลลัพธ์ทั้งหมดที่ได้จากการกด Run `week01.dart` ลงในกล่องด้านล่าง

```text

25.88
--- ข้อ 2 ---
83.17
95
68
--- ข้อ 3 ---
[Mint, Ploy, Beam]
--- ข้อ 4 ---
0
0
--- ข้อ 5 (Stretch) ---
[]
```

2. ทดสอบเพิ่มเองอย่างน้อย 1 กรณีที่ข้อมูลผิดปกติ เช่น ส่ง list ว่าง `[]` ให้ `average` หรือส่ง `''` ให้ `nicknameLength` แล้วบันทึกผล

- **กรณีที่ทดสอบ**: ส่ง List ว่าง `[]` ให้ฟังก์ชัน `average` และส่ง String ว่าง `''` ให้ฟังก์ชัน `nicknameLength`
- **ผลที่ได้**: `average([])` ได้ค่า `'0.00'` และ `nicknameLength('')` ได้ค่า `0`
- **ตรงกับที่คิดไว้ไหม เพราะอะไร**: ตรงกับที่คิดไว้ เพราะในฟังก์ชัน `average` ได้ใส่เงื่อนไขดักกรณี list ว่าง (`if (numbers.isEmpty) return '0.00';`) เพื่อป้องกันไม่ให้เกิด runtime error จากการเรียก `.reduce()` บน List ที่ไม่มีสมาชิก และในฟังก์ชัน `nicknameLength` สตริงว่าง `''` มีความยาวเป็น 0 อยู่แล้ว จึงคืนค่า 0 ได้อย่างถูกต้องและปลอดภัย

## อธิบายด้วยคำของตัวเอง (ข้อละ 3–5 บรรทัด)

1. ถ้าเขียน `nickname!.length` แล้ว `nickname` เป็น `null` จริงๆ จะเกิดอะไรขึ้น และทำไมข้อ 4 ใช้ `?.` กับ `??` แทน

   ตอบ: หากเขียน `nickname!.length` เป็นการใช้เครื่องหมาย Bang operator (!) เพื่อบังคับบอก Dart compiler ว่าตัวแปรไม่มีทางเป็น null แน่นอน แต่หากค่าที่ส่งเข้ามาตอน runtime เป็น null จริงๆ โปรแกรมจะ crash ทันทีและโยน Exception: Null check operator used on a null value ข้อ 4 จึงเลือกใช้ `?.` (Null-aware operator) เพื่อให้ข้ามการเรียก `.length` เมื่อค่าเป็น null และต่อท้ายด้วย `??` (Null-coalescing operator) เพื่อคืนค่าสำรองเป็น 0 แทน ทำให้โปรแกรมทำงานต่อได้อย่างปลอดภัยโดยไม่พัง

2. ในข้อ 3 `.where()` กับ `.map()` ทำหน้าที่ต่างกันอย่างไร และทำไมต้องปิดท้ายด้วย `.toList()`

   ตอบ: `.where()` ทำหน้าที่ "กรอง" (Filter) ข้อมูล โดยจะตรวจสอบสมาชิกแต่ละตัวตามเงื่อนไขที่กำหนดและเก็บเฉพาะตัวที่ได้ผลลัพธ์เป็น true ทำให้จำนวนสมาชิกอาจลดลงแต่ชนิดข้อมูลยังเหมือนเดิม ส่วน `.map()` ทำหน้าที่ "แปลง" (Transform) ข้อมูลของทุกตัวให้กลายเป็นค่าใหม่ จำนวนสมาชิกยังคงเท่าเดิมแต่ค่าข้างในเปลี่ยนไป (ในข้อนี้คือแปลงจาก Map ทั้งก้อนให้เหลือเพียง String ของชื่อคน) และสาเหตุที่ต้องปิดท้ายด้วย `.toList()` เนื่องจากผลลัพธ์ของ `.where()` และ `.map()` จะคืนค่าออกมาเป็นประเภท Iterable (แสดงผลในวงเล็บโค้ง) จึงต้องแปลงกลับเป็น List ให้สมบูรณ์เพื่อให้ตรงกับ return type ของฟังก์ชัน

## 3 บรรทัดว่าติดตรงไหนมากที่สุด

ถ้าไม่ติดอะไรเลย ให้เขียนว่าขั้นตอนไหนใช้เวลานานที่สุด

1. ขั้นตอนการตั้งค่าสภาพแวดล้อม Flutter SDK 3.50.1 และการเชื่อมต่อ PATH ใน Windows
2. ขั้นตอนการทำความเข้าใจ syntax ลูกศร `=>` และการทำงานของ `reduce()` กับ `fold()` ในภาษา Dart
3. ขั้นตอนการจัดการ null safety ด้วยเครื่องหมาย `?.` ร่วมกับ `??` ในข้อ 4
